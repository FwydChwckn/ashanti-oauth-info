Ashanti Production Backup

Ashanti Production Backup is an internal backup integration used to securely store encrypted PostgreSQL database backups for Ashanti Sales, Inc.

The integration uses Google Drive only as an off-site storage destination for encrypted backup files generated by the Ashanti production server.

Backup files are encrypted before being uploaded to Google Drive. This integration is not offered as a public application or service.

Google Drive Usage

Google Drive access is used only for creating, storing, reading, verifying, and managing Ashanti backup files.

Google account information is not sold, shared for advertising, or used for unrelated purposes.
