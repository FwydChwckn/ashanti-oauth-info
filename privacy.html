Privacy Policy

This privacy policy applies to the Ashanti Production Backup integration used by Ashanti Sales, Inc.

Purpose

The integration uses Google Drive to store encrypted PostgreSQL database backup files generated by the Ashanti production server.

Google User Data

Google Drive authorization is used only for backup-related operations, including uploading, reading, verifying, and managing backup files.

The integration does not use Google user data for advertising, profiling, marketing, or resale.

Backup Security

Ashanti database backups are encrypted before they are uploaded to Google Drive. Encryption credentials are maintained separately from the public information contained on this website.

Data Sharing

Google user data accessed by this integration is not sold or shared with third parties for advertising or unrelated purposes.

Access

This integration is intended solely for authorized Ashanti Sales, Inc. backup administration.
